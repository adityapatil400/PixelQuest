# PixelQuest Audio Assets

PixelQuest features a procedural 8-bit / 16-bit Web Audio API Synthesizer located in `js/ui.js` (`RetroAudioManager`).
The synthesizer generates sound effects dynamically:
- Coin pickup chime
- Jump boing / whoop
- Enemy squash stomp
- Player hurt crunch
- Stage clear fanfare
- Game over somber tune
- UI button hover blips and click confirms

You can also place external `.mp3`, `.wav`, or `.ogg` sound files in this directory for custom soundtracks or Foley effects.

# 🎮 PixelQuest – 2D Platformer Game

**PixelQuest** is a fun, interactive, browser-based 2D platformer game developed using HTML, CSS, and Vanilla JavaScript. Explore exciting worlds, jump across platforms, collect coins, defeat enemies, avoid dangerous obstacles, and unlock new levels.

Experience classic retro gaming with modern animations, smooth controls, and an immersive pixel-art environment.

---

## 🌟 Project Overview

Simple browser games often lack exploration, challenges, and progression.

PixelQuest addresses this by providing an interactive platform gaming experience where players can explore multiple environments, overcome obstacles, collect rewards, defeat enemies, and progress through increasingly challenging levels.

The game runs directly in the browser without requiring a backend or database.

---

## ✨ Features

### 🎮 Core Gameplay
- 2D side-scrolling platformer gameplay.
- Smooth player movement and jumping mechanics.
- Gravity and realistic falling physics.
- Multiple platforms and interactive environments.
- Camera-follow and scrolling system.

### 🪙 Coins & Scoring
- Collect golden coins throughout the game.
- Earn points for every collected coin (+10 pts) and hidden gems (+50 pts).
- Real-time score tracking.
- Track total coins collected.

### 👾 Enemies & Obstacles
- Walking Slime enemies.
- Flying enemies.
- Patrolling monsters.
- Spikes and dangerous traps.
- Lava pits and moving obstacles.
- Defeat enemies by jumping on them.

### 🌍 Multiple Levels
- **Level 1 – Green Forest:** Explore beginner-friendly platforms and enemies.
- **Level 2 – Lava Caves:** Navigate dangerous lava pits and moving platforms.
- **Level 3 – Dark Castle:** Face challenging obstacles and a final boss.

### 🏆 Progression System
- Level completion rewards.
- Unlock new levels.
- Level selection screen.
- Score and performance tracking.
- Save game progress.

### 🖥️ Game Interface
- Attractive pixel-art visual design.
- Animated game menus.
- Main menu and pause menu.
- Game Over and Level Complete screens.
- Responsive user interface.
- Full Screen Mode.

### 🔊 Audio & Settings
- Background music.
- Sound effects.
- Music and sound controls.
- Adjustable volume settings.

### 📱 Additional Features
- Keyboard controls.
- Mobile touch controls.
- Responsive gameplay.
- LocalStorage-based progress saving.
- Persistent high scores and unlocked levels.

## 🚀 Getting Started

Follow these steps to run PixelQuest locally.

### 1. Clone the Repository

```bash
git clone https://github.com/adityapatil400/PixelQuest.git
```

### 2. Navigate to the Project

```bash
cd PixelQuest
```

### 3. Open the Game

Open `index.html` in your browser.

Alternatively, use any static local server or the **Live Server** extension in Visual Studio Code:

```bash
# Python 3 built-in HTTP server
python3 -m http.server 8000

# Or using Node.js npx serve
npx serve .
```

Open `http://localhost:8000` in your web browser.
